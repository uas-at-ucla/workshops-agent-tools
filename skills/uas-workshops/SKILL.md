# UAS workshop editing

Fetch https://uas.seas.ucla.edu/workshops/agent.txt and follow it. It is the current guide to connecting, editing, files and grading.

If you cannot fetch URLs, `npx -y github:uas-at-ucla/workshops-agent-tools guide` prints the same text. The helper it describes is also bundled here as `scripts/uas-workshops.mjs` (Node 18+).
